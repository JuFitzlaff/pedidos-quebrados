# Feature: Cupom de desconto

## Regras de negócio (enunciado)
- O cupom `BEMVINDO10` dá 10% de desconto no subtotal do pedido.
- O cupom só vale para subtotal de **pelo menos R$ 100,00**.
- Se o subtotal for menor, o pedido segue **sem desconto** (não é erro).
- Um cupom que não existe deve ser **recusado**.
